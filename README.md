# ანდრია ურუმაშვილი — პორტფოლიო

დამწყები ვებ-დეველოპერის პორტფოლიო (ქართული).  
Vite + Tailwind CSS v4. სრულად რესპონსიული, მობილურზე burger მენიუ.

## გვერდები

- `index.html` — მთავარი, პროექტები, კონტაქტი
- `about.html` — ჩემ შესახებ, უნარები, სწავლა
- `team.html` — თანამშრომლები (JSONPlaceholder API)

## API (დავალება)

- **GET** `https://jsonplaceholder.typicode.com/users` — თანამშრომლების სია
- **GET** `https://jsonplaceholder.typicode.com/posts?userId={id}` — არჩეული მომხმარებლის პოსტები
- **POST** `https://jsonplaceholder.typicode.com/posts` — ახალი პოსტის mock შექმნა

მობილურზე ნავიგაცია: burger მენიუ (`src/nav.js`).

## გაშვება

```bash
npm install
npm run dev
```

ბრაუზერში: http://localhost:5173/

## Build

```bash
npm run build
npm run preview
```
